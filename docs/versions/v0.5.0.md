LanPin v0.5.0 — WinUI 主题与窗口更新。此版本为历史预发布快照，保留当时的实现与行为。

适配 ChatAIBox 的 WinUI 窗口和主题实现，加入跟随系统、浅色、深色、250 毫秒入场动效及按钮反馈，保留自定义背景。

**已知问题：实际鼠标拖动延迟与不同设备的桌面玻璃观感尚未完成实机测量。**

### 下载与运行
- `LanPin-v0.5.0-Windows-x64.zip`：完整程序包，包含对应源码及第三方许可证；请完整解压后运行 LanPin.exe。
- Windows 10/11 x64。包内已包含 .NET 10 和 WinUI 运行文件，无需另装运行时。
- 不同版本请解压到独立目录；旧版外观配置可能与新版共用本机数据目录。

### 联机角色与网络条件
加入方生成分享信息并监听 IPv6 TCP；存档接入方输入分享信息，连接加入方，将本机或内网存档接入。
双方 IPv6 须互通，加入方监听端口须可达。默认 LanPin 端口为 38443，不能与 Minecraft 存档端口混用。
实际存档电脑需对局域网开放并保持世界运行；双方使用不同玩家身份，游戏版本和模组匹配。
不提供无 IPv6 回退、中继、STUN、通用虚拟 IP 或自动重连。交换角色不能弥补一方完全缺少 IPv6 的情况。
