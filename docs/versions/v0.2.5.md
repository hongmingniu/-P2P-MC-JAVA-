### 下载与运行
- `LanPin-v0.2.5-Windows-x64.zip`：完整程序包，包含对应源码及第三方许可证；请完整解压后运行 LanPin.exe。
- Windows 10/11 x64。WPF 版本需要 .NET Windows Desktop Runtime，建议 .NET 10 x64。
- 不同版本请解压到独立目录；旧版外观配置可能与新版共用本机数据目录。

### 联机角色与网络条件
加入方生成分享信息并监听 IPv6 TCP；存档接入方输入分享信息，连接加入方，将本机或内网存档接入。
双方 IPv6 须互通，加入方监听端口须可达。默认 LanPin 端口为 38443，不能与 Minecraft 存档端口混用。
实际存档电脑需对局域网开放并保持世界运行；双方使用不同玩家身份，游戏版本和模组匹配。
不提供无 IPv6 回退、中继、STUN、通用虚拟 IP 或自动重连。交换角色不能弥补一方完全缺少 IPv6 的情况。
