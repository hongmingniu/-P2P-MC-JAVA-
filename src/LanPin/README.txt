LanPin Next v0.2.0 - 桌面界面预览版

运行
Windows 10/11 x64，需安装 .NET Windows Desktop Runtime 10 x64（本包不含运行时）。
下载：https://dotnet.microsoft.com/en-us/download/dotnet/10.0
解压整个程序包后运行 LanPin.exe，不要只复制 EXE。软件不需要管理员权限。

本版变化
1. 改为 WPF 桌面界面，使用内置 HarmonyOS Sans SC Regular / Bold。
2. 自绘标题栏，提供拖动、双击最大化、最小化、最大化 / 还原和关闭。
3. 角色选择、IPv6 / PIN、连接状态、存档卡片分区显示；网络参数可展开。
4. 主操作按钮固定在卡片底部，小窗口中也可见。
5. 存档卡片使用实际发现与代理端点通知，停止或过期后清理。
6. 页签和展开动画参考 WinUI 缓动，不使用弹跳过冲；支持“减少动效”。

自定义背景
打开“外观”，选择本地 PNG / JPG / BMP 图片，也可将一张图片拖进窗口。
单文件最大 24 MB，图片解码尺寸会限制至最长边 2048 像素；不修改原始图片。
支持背景模糊、深色遮罩、面板不透明度、完整显示 / 铺满以及默认渐变选择。
点击“恢复默认背景”即可清除当前图片选择。被缓存的图片及原始文件不因此删除。
外观设置与图片副本保存在本机 %LOCALAPPDATA%\LanPin 目录；不上传，不保存 IP、PIN 或账号信息。
移动原始图片不影响已经导入的软件背景。外观设置与旧版联机程序互不覆盖。

联机流程
加入方：选择角色和网卡，确认 IPv6 地址，点击“生成分享信息”，私下发送 IPv6、TCP 端口与 PIN。
存档接入方：选择角色和网卡，填写加入方 IPv6 与 PIN，点击“连接加入方”。端口默认 38443，可在网络选项中修改。
存档电脑：在 Minecraft Java 中“对局域网开放”并保持世界运行。它可以是存档接入方本机，也可以是其内网另一台电脑。
加入方：在 Minecraft 多人游戏列表中选择带“〈LanPin〉”前缀的存档；也可复制软件中的备用地址直接连接。
发现受阻时，存档接入方可在网络选项中填写游戏端点，例如 127.0.0.1:5222。
双方需要互通 IPv6，加入方监听端口须可从存档接入方访问。软件不修改代理、路由、防火墙或系统安全设置。
游戏与模组版本须兼容，开服和加入使用不同玩家身份。此版仍无中继和自动重连，也不提供通用虚拟 IP。
停止或关闭软件会释放当前会话、清除界面 PIN 和存档卡片；日志只保留在进程内存。

验证范围
Release 构建通过，零警告、零错误。
核心自测通过：真实 IPv6 回环 TLS、PIN 验证、组播发现、并发 4 MiB 数据往返与端口释放。
新增窗口控制层集成检查通过：从界面逻辑启动配对、显示真实连接状态、接收存档卡片、转发游戏 TCP 数据、停止后清空敏感状态。
外观检查通过：字体实际解析、自绘标题栏配置、默认及小窗口排版、背景导入 / 重载 / 还原、参数保存、无效图片拒绝。
排版检查使用实际 WPF 视觉树渲染；桌面截图通道超时，原生拖动 / 最大化的鼠标交互尚未完成自动验收。
此版尚未重新运行真实 Minecraft 客户端或异地双机实测；此前版本已通过 1.21.11 同机游戏联机。
这是预览版，未经独立安全审计及代码签名。

开发与检查
源码在 src/LanPin。需要 Windows 与 .NET SDK 8 或更新版本，无第三方 NuGet 依赖。
dotnet publish src/LanPin/LanPin.csproj -c Release -o build/LanPin
LanPin.exe --self-test：核心网络自测，结果写入程序目录。
LanPin.exe --ui-check <输出目录>：在隔离配置中进行外观及窗口控制层集成检查，并输出截图和报告。
