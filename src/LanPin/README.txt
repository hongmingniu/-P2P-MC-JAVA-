LanPin Next v0.3.0 — 桌面界面预览版

运行
Windows 10 / 11 x64，需 .NET Windows Desktop Runtime 10 x64（本包不含运行时）。
运行时下载：https://dotnet.microsoft.com/en-us/download/dotnet/10.0
解压整个程序包后运行 LanPin.exe；请关闭旧版，不要只替换 EXE。无需管理员权限。

新版界面
首页采用大面积留白、左下标题、右下连接状态与主要操作、底部导航。
界面为浅色暖雾主题，使用内置 HarmonyOS Sans SC 字体，保留自绘标题栏及参考 WinUI 的缓动。
点击“开始联机”打开右侧连接抽屉，角色、IPv6、PIN 均在抽屉中设置。
网卡、TCP 端口和手动游戏地址收在“网络选项”中。
运行中首页显示“连接详情”和“断开”，可通过“查看存档”查看真实发现的局域网存档并复制备用地址。
关闭抽屉不会断开连接。Esc 可关闭当前浮层；页面切换收起连接抽屉。

联机
加入方：想加入朋友世界的人。点击“开始联机”，选择“加入方”，确认能供对方访问的 IPv6，然后生成分享信息。
将 IPv6、TCP 端口和 PIN 私下发送给存档接入方。端口默认 38443。
存档接入方：在实际存档所在内网运行，选择相应角色，填写加入方信息并连接。
实际开服电脑可以是接入方本机，也可以是同一内网另一台电脑。在 Minecraft Java 中对局域网开放并保持世界运行。
加入方在 Minecraft 多人游戏中选择带〈LanPin〉前缀的存档。列表未出现时，可从“查看存档”复制备用地址直接连接。
发现受阻时，接入方可在网络选项手动指定游戏地址，例如 127.0.0.1:5222。
双方 IPv6 需互通，加入方监听端口需允许连接。双方游戏版本、模组与身份需兼容，不可使用同一玩家身份。
没有中继、自动重连或通用虚拟 IP。程序不修改系统路由、代理或防火墙。
停止后释放会话并清除 PIN 和存档状态。日志仅保留在进程内存。

背景与材质
外观页可以导入 PNG / JPG / BMP，或直接拖入一张图片，最大 24 MB。
原始图片不会修改；本地副本会限制解码尺寸，缓存于 %LOCALAPPDATA%\LanPin。
支持图片模糊、磨砂遮罩、背景图混合、面板不透明度、完整显示 / 铺满、减少动效。
“恢复默认背景”只取消选用，不删除原始图片或此前缓存。
首页底部使用渐变遮罩，帮助背景图上的标题和按钮保持清晰。
Windows 10 使用轻量原生模糊，Windows 11 22H2 及更新系统优先使用 Desktop Acrylic。
系统的“透明效果”需开启；高对比度、系统策略和设备环境可能限制材质。系统不支持时回退到普通背景。
软件不改变系统透明开关，也不使用整窗 Opacity 来降低文字透明度。
原生窗口与内容层均裁剪圆角；最大化恢复直角，还原后恢复圆角。
自定义图片及设置仅保存在本机，不上传，也不保存 IP、PIN 或账号。

验证与限制
发布源码完成隔离 Release 构建；联机逻辑、背景导入、设置保存、连接抽屉和窗口边界完成自动化检查。
检查使用程序自身视觉树及真实 IPv6 回环、组播和 TCP 连接；详见“验证范围.txt”。
界面预览为程序渲染，不能替代 Windows 桌面合成的视觉确认或实际鼠标拖动延迟测试。
本版没有重新进行真实 Minecraft 或异地双机游戏验收。未经独立安全审计及代码签名。

开发
完整源码在 src/LanPin。需要 Windows 与 .NET SDK 8 或更新版本，无第三方 NuGet 依赖。
dotnet publish src/LanPin/LanPin.csproj -c Release -o build/LanPin
LanPin.exe --self-test：核心网络自测，结果写入程序目录。
LanPin.exe --ui-check <输出目录>：隔离配置中的界面及联机集成检查，输出排版图和报告。
